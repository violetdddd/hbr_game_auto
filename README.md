# HBRTool

HBRTool 是一个面向《Heaven Burns Red》的 Windows 战斗排轴编辑与自动执行工具。通过图形界面和本地数据库选择角色、技能、目标和回合行动，生成文本 `.hbrf` 脚本，并按脚本自动操作游戏窗口（自动操作需要管理员权限）。目前主要适配国服炽焰天穹，因为我没有国际服的号，成濑光等有特殊技能的角色和打分EX模式的5OD无法测试，尽管本地数据库已经包含全部日服角色（会定期上传Github更新）

## 主要功能

- **队伍管理**：每队六名角色，支持队内交换位置、昵称与风格筛选（软件内含有轻量级本地风格数据库）；双队伍 Tab 可编辑异时层排轴，非当前队伍回合以红色边框提示并冻结内部编辑。
- **可视化排轴**：普通回合可以选择角色风格、技能、友方/敌方目标，以及回合、追加回合、前置/后置 OD 和 Bonus；支持回合复制、删除、移动及三名前排角色换位。脚本会自动处理技能属性切换和关闭自动战斗。
- **异时层与特殊行动**：异时层行动支持自动跳过剧情、自动点击切换队伍（骨龙一阶段不需要使用点击切换队伍功能）。waki小按钮和总攻击以特殊回合行动的形式添加。可怜怜切换姿态和司令官鬼神化的专属前排行动通过普通回合手动添加，不要依赖游戏内自动切换姿态。
- **OD 与追击检测**：配置 OD 发动与「凹追击」功能；执行脚本时可检测 OD 条件，并在条件不满足时触发重试流程（主要适配高分挑战）。
- **HBRF 导入导出**：读取、编辑和保存脚本；导出时收集角色用到的技能，并在文件尾部保留风格元数据注释。仅使用一支队伍时输出 6 名角色，使用两支队伍时输出 12 名角色；参与导出的每支队伍必须满员。
- **外部排轴转换**：GUI 提供从 `hbr-tool.com` 保存的 SAV 文件及从 `hbr-axletool.pages.dev` 导出的 JPG 文件（理论上该网站自己能解析的GUI也能解析，异时层双队暂不适配）转换为 `.hbrf` 文件的入口，至此可做到全GUI自动抄作业了！
- **自动战斗与光球刷取**：连接游戏窗口，选择脚本回车后，按脚本配置技能，剩下的都交给软件自动战斗即可；提供单次战斗、光球重复刷取、执行日志及终止操作。
- **技术模拟战**：提供独立的重复打牌入口、次数设置与日志显示，目前默认为31C普通战斗。

## 基本使用

0. 游戏自动化需要 Windows 管理员权限，直接打开exe文件运行即可。
1. 在「HBRF 编辑器」选择 6 名角色；异时层需要两队时分别配置 12 名角色。
2. 添加回合或特殊行动，设置每回合三名前排角色的技能、目标及 OD。
3. 保存为 `.hbrf`；也可打开已有 `.hbrf`，或先转换 SAV/JPG 文件再编辑保存。
4. 在「普通战斗」中选择 `.hbrf`、确认游戏窗口标题及分辨率，然后执行单次或重复战斗。


## 项目进阶说明

### hbrf文件格式

本质是文本文档（`#`开头为注释），主要分为3个部分：
 1. 文件头，定义所有角色昵称（6或12行）与数据库技能繁体中文名称（可切换技能用`/`分割，左侧为开局默认技能选择）
 2. 每回合的行动轴，具体含义如下：

| Action 格式 | 功能 |
|---|---|
| `T1 = 0; ······` | 普通回合，`=`前为回合的标签，`=`后为指定OD，0为不发OD，1至3为后置OD，-1至-3为前置OD |
| `······ ; 角色C: 1,0` | 第一个数字代表使用该角色在文件头中的第几个技能，0为普攻/指挥；第二个数字代表技能的目标，0为无目标，1-6为文件头己方角色顺序，7-9分别为三体的左、中、右，若双体则只有8、9有意义 |
| `Team = 1` / `Team = 2` | 切换脚本当前使用的队伍，不进行游戏内点击 |
| `change` | 点击游戏内的切换队伍按钮，不改变脚本当前 Team |
| `skip` | 点击跳过剧情按钮 |
| `skill \| 角色名 \| 技能编号 \| 前排位置` | 切换指定角色的可切换技能 |
| `kelian \| 角色名 \| 前排位置` | 执行可怜的特殊按钮（切换姿态） |
| `siling \| 角色名 \| 前排位置` | 执行司令的特殊按钮（鬼神化） |
| `waki` | 点击魔界骑兵按钮 |
| `attack` | 点击总攻击按钮 |
| `check_od` | 在下一次发动 OD 前检查是否满足凹追击条件，不满足则重开战斗 |

 3. 结尾的注释包含风格信息，用于GUI显示，与自动战斗运行无关

> 自动战斗只依赖hbrf，因此理论上可以记事本排轴，不需要注释的风格信息、可以随便为技能和每回合的标签命名，可以通过这种方式绕过GUI的某些检查，不过几乎所有功能GUI即可完成，大多数人用不到这个方法

### 主要项目模块

| 模块 | 作用 |
|---|---|
| `hbr_gui.py` | 基于 PySide6 的图形编辑器，负责排轴、文件导入导出与任务控制 |
| `hbrf/model.py` | HBRF 数据结构、解析、验证和序列化 |
| `fight.py` | 基于 cv2 的图像模板匹配，负责自动战斗指令执行、角色站位与技能操作 |
| `run_battle.py` | 独立进程战斗执行入口 |
| `config/`、`assets/` | 分辨率配置、识别模板、角色/技能数据库和图片等 |
